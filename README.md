# ブランドサイト

## 制作背景
CSSのpositionプロパティや要素の重なりの理解を深めるため制作しました。<br>
コンテンツの固定表示や重ね合わせなど、レイアウト表現の幅を広げることを目的としています。

---

## 使用技術
HTML, CSS

---

## 工夫した点
CSS設計を意識し、BEMやコンポーネント化、CSS変数の活用を行いました。<br><br>
positionを用いたレイアウトにおいては、レスポンシブ対応を意識し、左右の位置指定に%を使用することで画面サイズに応じた柔軟な配置を実現しました。<br>
また、ブラウザのズーム機能で200%まで拡大した際にもレイアウトが崩れないことを確認しました。

---

## 苦労した点
要素が上下のコンテンツと重なってしまったり、意図しない位置に表示されたりするなど、positionを用いたレイアウトに苦労しました。<br>
また、親要素に高さを指定しないことで背景が正しく表示されない問題もありました。

---

## 学んだこと
改めて仕様を調べ直すとともに、一つひとつのコードの役割を理解しながら検証を行いました。<br>
その結果、positionやtransformの仕組みについて理解を深めることができ、意図したレイアウトを再現できるようになりました。
